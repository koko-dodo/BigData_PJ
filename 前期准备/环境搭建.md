## 五、重要注意事项

### 1. 不要再次执行 format

禁止执行：

bash hdfs namenode -format 

原因：

会清空整个 HDFS 元数据。

---

### 2. 集群启动命令

若服务器重启：

启动 HDFS：

bash start-dfs.sh 

启动 YARN：

bash start-yarn.sh 

启动 Spark：

bash start-master.sh start-workers.sh 

---

### 3. 集群关闭命令

bash stop-workers.sh stop-master.sh stop-yarn.sh stop-dfs.sh 

---

### 4. 查看集群状态

bash jps 

bash hdfs dfsadmin -report 

---

### 5. HDFS 常用命令

上传：

bash hdfs dfs -put localfile /data/ 

查看：

bash hdfs dfs -ls / 

读取：

bash hdfs dfs -cat file 

删除：

bash hdfs dfs -rm file
