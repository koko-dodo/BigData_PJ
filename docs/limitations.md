# 已知局限与后续验证

1. **场景身份**：六个原始场景被汇总，分组键未包含 cloudbed。需核对同名对象是否跨场景重复，再决定加入场景标识；变更后必须重新实验。
2. **序列计数**：历史的 8,730 按对象/KPI 去重，和检测键不完全一致。新脚本输出两个计数，真实结果待复核。
3. **无标签评测**：异常数量的变化不能替代准确率、召回率或误报率。所谓“高置信”仅表示同时满足统计规则。
4. **IQR 退化**：IQR 为零时跳过 IQR 判断，可能漏掉长期常量中的少量突刺；V2 AND 也受影响。
5. **窗口边界**：V3 包含当前点，可能稀释突刺；按行而非时间定义窗口，同时间戳记录没有稳定的次排序键。
6. **融合基线**：V4 按类型跨对象计算均值/标准差；缺失填零、重复点平均和 Top-K 频率选择均可能影响结果。当前仅检测共同越阈，没有建立因果或相关性模型。
7. **数据质量**：尚未系统处理无限值、异构 CSV schema、重复点与时间对齐。原始数据缺失，无法在此次整理中确认其实际发生程度。
8. **运行证据**：历史优化有实现与过程记录，没有量化性能基准；本地合成样例不能证明原集群的吞吐或真实检测质量。

整理阶段保持原算法含义。上述涉及方法变化的改进应作为独立实验，保存新参数、环境与结果，避免将旧数字用于新算法。
