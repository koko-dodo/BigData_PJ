# 合成样例

运行 `bash scripts/run_demo.sh` 自动生成样例并依次运行清洗及四种检测方法。
需要 Python 3、Spark 3.5.1（Scala 2.12）及兼容 Java 环境，运行不需要 HDFS。

生成器位于 `scripts/generate_demo.py`：构造 240 个一分钟采样点，覆盖五类指标；service 有四个 KPI，其余每类两个 KPI。第 150、200 个点注入共同突刺，每类额外插入一条非法时间戳记录。

清洗后预期 2,880 条记录、12 条检测序列。Demo 对 service 运行四个检测脚本，并检查两处突刺均被检出；另用独立输出目录验证 V2 全类型入口及五类 summary 与异常输出的一致性。这个检查验证基本执行链路，不是准确率评测，也不能替代真实集群验证。

样例、Parquet、日志写入被 Git 忽略的 `.demo-runs/run.*`，每次使用新目录。所有样例均为人工构造，不是原实验数据或原实验结果。
